Caddy Proxy Manager exposes a full REST API under `/api/v1/` that lets you manage every aspect of the proxy — from creating hosts and certificates to configuring security rules and multi-instance sync. The API follows OpenAPI 3.1.0; interactive documentation is available at `/api-docs` in your dashboard.

## Base URL

All endpoints share a common path prefix:

```
/api/v1/
```

Requests must include valid authentication on every call. See [Authentication](/api/authentication) for details.

## Interactive docs

An embedded OpenAPI playground is available at `/api-docs` in your running dashboard instance. You can authenticate directly in the UI and try every endpoint without writing any code.

<Tip>
  The interactive docs are generated from the live OpenAPI spec served at `/api/v1/openapi.json`.
</Tip>

## Response format

### Success responses

Successful requests return either the affected resource as a JSON object, or a confirmation envelope for operations that do not return data:

```json
{ "ok": true }
```

Collection endpoints return a JSON array of resource objects.

### Error responses

All errors return a JSON object with a single `error` field:

```json
{ "error": "string describing the problem" }
```

## HTTP status codes

| Code | Meaning |
|------|---------|
| `200` | Request succeeded; resource returned or `{"ok": true}` |
| `201` | Resource created; new resource object returned |
| `400` | Bad request — invalid input or missing required fields |
| `401` | Unauthorized — missing or invalid credentials |
| `403` | Forbidden — authenticated but insufficient permissions |
| `404` | Not found — resource does not exist |
| `500` | Internal server error — Caddy configuration apply failed |

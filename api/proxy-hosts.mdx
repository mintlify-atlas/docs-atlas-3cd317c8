---
title: 'Proxy hosts API: manage HTTP/HTTPS reverse proxies'
description: 'Create, read, update, and delete HTTP/HTTPS reverse proxy hosts via the Caddy Proxy Manager REST API, including TLS, load balancing, and WAF options.'
---

The proxy hosts API gives you programmatic control over every HTTP and HTTPS reverse proxy entry in Caddy Proxy Manager. Each proxy host maps one or more domain names to one or more upstream servers and carries optional settings for TLS termination, WebSocket support, access control, load balancing, geographic blocking, WAF rules, path rewrites, and more. All endpoints require a valid bearer token or an active session cookie.

<Note>
  All requests must include an `Authorization: Bearer <token>` header or a valid `authjs.session-token` session cookie. Tokens are created on the Profile page.
</Note>

---

## List proxy hosts

<br />

**`GET /api/v1/proxy-hosts`**

Returns an array of all proxy host objects.

```bash
curl https://your-cpm-host/api/v1/proxy-hosts \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Response

Returns `200` with an array of [ProxyHost](#proxy-host-object) objects.

---

## Create a proxy host

<br />

**`POST /api/v1/proxy-hosts`**

Creates a new HTTP/HTTPS reverse proxy host. Caddy reloads its configuration automatically after a successful create.

```bash
curl -X POST https://your-cpm-host/api/v1/proxy-hosts \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My App",
    "domains": ["app.example.com"],
    "upstreams": ["localhost:3000"],
    "ssl_forced": true,
    "hsts_enabled": true,
    "allow_websocket": true,
    "enabled": true
  }'
```

## Get a proxy host

<br />

**`GET /api/v1/proxy-hosts/{id}`**

Returns a single proxy host by its integer ID.

```bash
curl https://your-cpm-host/api/v1/proxy-hosts/1 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Path parameters

<ParamField path="id" type="integer" required>
  The proxy host ID.
</ParamField>

### Response

Returns `200` with a [ProxyHost](#proxy-host-object), or `404` if not found.

---

## Update a proxy host

<br />

**`PUT /api/v1/proxy-hosts/{id}`**

Replaces the configuration for an existing proxy host. The request body uses the same shape as [Create a proxy host](#create-a-proxy-host). Caddy reloads automatically on success.

```bash
curl -X PUT https://your-cpm-host/api/v1/proxy-hosts/1 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My App",
    "domains": ["app.example.com"],
    "upstreams": ["localhost:4000"],
    "ssl_forced": true,
    "enabled": true
  }'
```

### Path parameters

<ParamField path="id" type="integer" required>
  The proxy host ID.
</ParamField>

### Response

Returns `200` with the updated [ProxyHost](#proxy-host-object), `400` on validation error, or `404` if not found.

---

## Delete a proxy host

<br />

**`DELETE /api/v1/proxy-hosts/{id}`**

Permanently removes a proxy host. Caddy reloads automatically after deletion.

```bash
curl -X DELETE https://your-cpm-host/api/v1/proxy-hosts/1 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Path parameters

<ParamField path="id" type="integer" required>
  The proxy host ID.
</ParamField>

### Response

Returns `200` with `{"ok": true}`, or `404` if not found.

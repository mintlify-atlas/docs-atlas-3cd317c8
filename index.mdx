Caddy Proxy Manager gives you a powerful, browser-based control plane for [Caddy Server](https://caddyserver.com/). Instead of editing JSON configs or Caddyfiles by hand, you manage reverse proxies, TLS certificates, access control, security rules, and traffic analytics through a clean dashboard — with every change tracked in a full audit log and exposed via a REST API.

## Get started in three steps

<Steps>
  <Step title="Deploy with Docker Compose">
    Clone the repository, copy `.env.example` to `.env`, set your credentials, and run `docker compose up -d`. The dashboard is available at `http://localhost:3000`.
  </Step>
  <Step title="Create your first proxy host">
    Log in as admin, navigate to **Proxy Hosts**, click **Add Proxy Host**, enter your domain and upstream address, and save. Caddy automatically obtains a TLS certificate.
  </Step>
  <Step title="Explore security and automation">
    Enable the WAF, configure geo blocking, set up mTLS for sensitive services, or use the REST API and audit log for automation and compliance.
  </Step>
</Steps>

<Note>
  Caddy Proxy Manager requires Docker and Docker Compose. See the [Quick Start](/quickstart) for the full setup walkthrough.
</Note>
